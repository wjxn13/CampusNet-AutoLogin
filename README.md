# 校园网-自动登录  

## 项目简介  
这是一个用于 **北方工业大学学校校园网** 自动登录的 Python 脚本，帮你免去手动输入账号密码的繁琐~  


## 功能  
- 自动读取配置文件/环境变量中的账号密码（需自行配置）；  
- 模拟网页请求完成校园网登录；  
- 支持断线重连（可选功能，视实现逻辑而定）。  


## 使用方法  
### 1. 安装依赖  
先确保本地有 Python 环境，然后执行：  
bash
pip install -r requirements.txt
  


### 2. 配置登录信息  
在 `login.py` 中填写你的校园网账号、密码（或通过环境变量/配置文件注入，视代码逻辑调整）。  


### 3. 运行脚本  
直接执行 Python 文件即可：  
bash
python login.py
  


## 注意事项  
- 校园网登录接口可能随学校政策更新，若脚本失效需及时调试；  
- 密码建议加密存储或使用环境变量，避免明文泄露风险；  
- 本项目仅作学习交流，严禁用于非授权场景。
